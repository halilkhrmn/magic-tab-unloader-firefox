Magic Tab Unloader

Unload idle Firefox tabs automatically, the same as right-click → Unload Tab, with rules per site.

Download Source on GitHub

What it does

Automatic unload

Tabs that sit idle past a time limit are unloaded. They stay in your tab bar and reload when you click them. The active tab and tabs playing audio are never touched.

Profiles per site

Match by hostname and pinned state. Give docs.example.com two hours, a chat tab five minutes, and your bank "never".

Auto-refresh for notification dots

Unloaded tabs are reloaded in the background every few minutes you choose, so sites can show their notification dot or title counter, then unloaded again. Tabs with news are counted on the toolbar badge.

Active hours

Apply a profile only on weekdays, during work hours, or overnight. Overnight windows such as 22:00–06:00 work.

Right-click whitelist

"Never unload this site" on any page or tab. Choose it again to undo.

Simple popup

Pause, idle time, "never unload pinned tabs" and auto-refresh are one click away in the toolbar popup. Everything else is in the settings page.

Backup

Export your profiles to a JSON file and import them on another computer.

Private by design

No accounts, no analytics and no network requests. Settings stay in your browser.

Install

  1. Download the latest .xpi from the releases page.
  2. In Firefox open about:addons, click the gear icon and choose Install Add-on From File….
  3. Open the extension's settings to create your first profile.

Unsigned builds load permanently only in Firefox Developer Edition, Nightly or ESR with xpinstall.signatures.required set to false. A listing on addons.mozilla.org is planned.

Greyed-out tabs

Firefox greys out tabs unloaded from its right-click menu, but not tabs unloaded by an extension. Tick Grey out the icons of tabs this extension unloads in the settings and the extension greys the icon itself, using the same grey, half-transparent look plus a small sleeping "zZ". It asks for permission to access all sites, only when you tick the box. Prefer not to grant that? Open about:config and set browser.tabs.fadeOutUnloadedTabs to true instead.

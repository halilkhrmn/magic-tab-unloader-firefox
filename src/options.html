Tab appearance

Firefox greys out tabs unloaded from its own right-click menu, but not tabs unloaded by an extension. This option swaps the page icon for a grey, half-transparent copy with a small sleeping "zZ" just before the tab is unloaded. It needs permission to access all sites (Firefox asks when you tick the box); the icon is only read and redrawn on your computer.

Alternatively, open about:config and set browser.tabs.fadeOutUnloadedTabs to true to let Firefox grey out every unloaded tab. Extensions cannot change that setting.

Profiles

The first matching profile wins. Hosts match the domain and its subdomains (github.com, *.google.com); leave empty to match any site. A profile with active hours only applies inside that window.
